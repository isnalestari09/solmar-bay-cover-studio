Solmar Bay Cover Studio — a web app that turns your photo into GTA-style poster art for the fictional game Solmar Bay (Dani Reyes, getaway driver, coastal sunset, lighthouse docks, boat chase). Multi-panel posters with bold caption lettering and a sunset or neon colour grade, exported as a PNG to share. All art is drawn in code; nothing from Rockstar.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Pick a size (1080×1080, 1080×1350, 1920×1080), fill each panel with a drawn Solmar Bay scene or your own photo (click a panel, drag to position, zoom to crop), write the title, subtitle and tagline, pick a colour grade, and hit Export PNG.
